# Base de conocimiento del taller

Notas de la red MotorRed para el diagnóstico. Cada nota tiene propiedades (tipo, sistema, códigos, categorías y horas) que el RAG guarda como metadatos.

- Fallas: [[Falla de encendido]], [[Pastillas de freno desgastadas]], [[Batería descargada]], [[Catalizador]], [[Correa de accesorios]]...
- Mantenimiento: [[Mantenimiento motor gasolina]], [[Mantenimiento motor diésel]].
- Procedimientos: [[Lectura de códigos OBD-II]].
- Políticas: [[Garantía de mano de obra del taller]].

Para crear una nota nueva use la plantilla de la carpeta `_plantillas` y, al terminar, vuelva a indexar.
